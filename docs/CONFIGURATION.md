# 配置说明

建议通过工作台“连接设置”和“养鱼”页面保存配置。每个新安装都会生成自己的 data/live，发布包不包含作者的账号或偏好。

## 连接

| 项目 | 默认值或用途 |
| --- | --- |
| 工作台 | http://127.0.0.1:18061 |
| 演示版 | http://127.0.0.1:18062，数据隔离 |
| 平台服务 | http://127.0.0.1:18060 |
| DEEPSEEK_API_KEY | 可选环境变量，优先于页面保存的密钥 |
| DSH_NODE | 可选，指定 DSH 会话调用的 Node 可执行文件 |
| DSH_HOME | 可选，DSH 目录，用于寻找其 Node 运行时 |

代码当前接受 deepseek-flash 和 deepseek-v4-pro 两个模型名称，前者走图文路径，后者在本版中按文本处理。它们是当前实现的选项，不保证上游长期提供同名模型；若 API 返回模型不可用，需要更新 lib/model.js、配置校验及页面选项后再使用。

模型请求固定发往 https://api.deepseek.com/chat/completions。模型会接收当次阅读偏好、选中笔记的正文、评论和限定数量的图片 URL。

## 默认行为

- 发送主开关关闭；先阅读和生成草稿，再决定是否开启。
- 默认候选 15 条、读取 5 条、精读 3 条，可在页面修改。
- 养鱼窗口为 20:00–24:00，每段最低 1 次，每日最多 2 次；最低次数受每日上限、运行状态和窗口剩余时间约束。
- 养鱼内容默认带北京关键词优先，每轮本地候选 3 条；平台筛选面板默认关闭，实际结果不保证同城或近期。
- 主人 ID 留空，需要自己填写；分享默认开启，真实 @ 默认关闭。
- 陌生人回复默认草稿；点赞默认启用，每日最多 10 次。开启互动前请核对各项开关。
- 评论、回复没有本地每日次数上限，但有防重复、账号核验和不确定发送结果保护。
- 回访默认概率 30%，同一人间隔 72 小时；只准备手动待办。
- 收件箱默认每 300 秒扫描一次，非全天模式。

examples/fish.example.json 是默认配置的无账号样例，用于了解结构；正常使用不必手工复制。人设语气与流程要求在 fish/AGENTS.md。

## 本地文件

data/live 保存运行配置、密钥、草稿、阅读记录、养鱼状态和两本日记；data/demo 用于演示；data/xhs-service 保存登录和服务日志。不要把这些目录提交到 Git，也不要把原始日志直接粘贴到公开 Issue。
